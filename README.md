Patchwork Pattern Generator - Python

A Python program that generates visual patchwork designs based on user-selected colours and pattern sizes.

The program allows a user to select three colours and generate different patchwork layouts in different sizes (5x5, 7x7, and 9x9 patterns). It uses the graphics.py library to draw shapes on a graphical window through coordinate-based positioning. 

Features:
- User input validation for colour choices
- Generates multiple patchwork layouts
- Uses functions to organise drawing and pattern generation
- Creates graphical designs using coordinate calculations

Technologies:
- Python
- graphics.py
- Functions and modular programming
- Loops and conditional logic
